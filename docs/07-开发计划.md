# 07 开发计划与里程碑

## 1. 里程碑总览

| 里程碑 | 主题 | 交付物 | 验收标准 | 预估 |
| --- | --- | --- | --- | --- |
| **M0** | 骨架跑通 | CMake 工程、公共库、epoll 服务端回显、客户端连上 | 客户端发一行，能收到服务端回显 | 0.5 天 |
| **M1** | 协议与日志 | 帧编解码 + TLV + CRC + 异步日志 + 单测 | 畸形帧测试全过，ASan 干净 | 1 天 |

## 3. 风险与应对

| 风险 | 概率 | 应对 |
| --- | --- | --- |
| epoll 单线程成为瓶颈 | 中 | M5 压测暴露后改多 reactor，协议不变 |
| 终端 UI 在特殊终端下错乱 | 高 | 只支持 xterm 系（WSL/Windows Terminal/gnome-terminal）；提供 `--plain` 纯行模式兜底 |
| 宽字符宽度判断不准 | 中 | 使用区间表 + 允许 `--ambiguous-width=1/2` 配置 |
| 存储 fsync 拖慢延迟 | 中 | group commit 已缓解；提供 `--sync=batch/always` 调节 |
| 时间不足导致半成品 | 高 | 每个里程碑独立可运行，M3 起即"可用产品" |

## 4. 开发工作流

1. 每个里程碑开始前，在 `PROGRESS.md` 写"计划"小节。
2. 编码 → `scripts/check.sh`（Debug+ASan 编译 + 单测）→ 手工端到端验证。
3. 结束写"结果/偏差/遗留"。**偏差必须写清原因**，不许静默跳过。
4. `docs/02-模块清单.md` 的状态列同步更新。
