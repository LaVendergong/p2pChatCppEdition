# 05 终端界面设计

## 1. 屏幕布局

```
┌──────────────────────────────────────────────────────────────┐
│ #public  alice,bob  msgs:1024                      ● 14:32:05 │  ← 状态栏（反显）
├──────────────────────────────────────────────────────────────┤
│ 14:20:11 alice: 今天服务器有点慢                              │
│ 14:20:33 bob:   重启一下试试                                  │  ← 消息区（可滚动）
│ 14:21:02 alice: 已经重启好了                                  │
│ 14:21:10 * alice 加入了房间                                   │
├──────────────────────────────────────────────────────────────┤
│ > 这是一条还没发出去的消息▏                                  │  ← 输入区
└──────────────────────────────────────────────────────────────┘
```

行数 = 终端高度（`ioctl TIOCGWINSZ`）；消息区 = 高度 - 2；输入区固定 1 行（M4 支持折行）。

## 2. 终端模式

| 项 | 做法 |
| --- | --- |
| 原始模式 | `tcgetattr` 保存原 termios，`cfmakeraw` 修改：关闭 ICANON/ECHO/ISIG，`VMIN=0 VTIME=0` |
| 备用屏幕 | 进入时 `\x1b[?1049h`，退出时 `\x1b[?1049l`（`atexit` + 信号处理里也必须还原） |
| 隐藏光标 | 渲染期间 `\x1b[?25l`，输入区重绘后 `\x1b[?25h` |
| 窗口变化 | `SIGWINCH` → 自管道/`signalfd` 唤醒 poll → 重新计算布局、整屏重绘 |
| 退出还原 | 强制 `tcsetattr(TCSAFLUSH)`，即使 Ctrl-C / SIGHUP / 崩溃（`atexit` 注册） |

**关键约束**：任何情况下都不能把用户终端留在 raw 模式。`TerminalGuard` 的析构函数负责还原，
且信号处理函数里直接调用 `tcsetattr`（async-signal-safe）。

## 3. 渲染策略

- 维护一个"屏缓冲" `vector<string>`（每行一个已上色字符串，只存可见区域）。
- 每次重绘计算新旧屏缓冲的差异，只对变化的行发 `\x1b[<row>;1H` + 行内容 + `\x1b[K`。
- 全量重绘仅在 resize / 房间切换时发生。
- 输出统一走 `std::string out; out.reserve(64KB)` 拼好后**一次 `write`**，减少闪烁。

### 3.1 字符宽度

- 中文占 2 列，需要用 UTF-8 解码后按 `wcwidth` 语义计算（自实现区间表：`0x1100-0x115F`,
  `0x2E80-0xA4CF`, `0xAC00-0xD7A3`, `0xF900-0xFAFF`, `0xFE30-0xFE6F`, `0xFF00-0xFF60`,
  `0xFFE0-0xFFE6`, `0x1F300-0x1F64F` 等常见区间）。
- 截断时不能切断多字节序列或把宽字符对半切（补空格）。

### 3.2 安全

**必须剥离输入文本里的 ANSI 控制序列**（`ESC [`, `ESC ]`, 以及 `\r` 等），否则恶意用户可以
伪造"另一条消息"、改标题、甚至触发终端漏洞。剥离在渲染入口统一做一次。

## 4. 输入编辑（editor 模块）

以"字符"为单位维护缓冲（解码为 `vector<char32_t>` 或用 UTF-8 边界索引），游标是字符下标。

| 按键 | 行为 |
| --- | --- |
| 可打印字符 | 插入到游标处（UTF-8 多字节整体处理） |
| Backspace (0x7F) | 删除游标前一个字符 |
| Delete (`ESC [ 3 ~`) | 删除游标处字符 |
| ← / → | 游标移动一个字符 |
| Home (Ctrl-A) / End (Ctrl-E) | 行首/行尾 |
| Ctrl-U / Ctrl-K | 删除到行首 / 行尾 |
| Ctrl-W | 删除前一个词 |
| ↑ / ↓ | 历史输入（最多 200 条，去重连续相同项） |
| Enter | 提交；`/` 开头走命令解析 |
| Ctrl-C | 清空当前输入；连按两次退出 |
| Ctrl-D | 空输入时退出 |
| Ctrl-L | 强制全屏重绘 |
| Ctrl-R | 重发最近一条失败消息（行尾 `!`）；复用原 client_msg_id，服务端幂等去重 |

粘贴大段文本：单次 read 可能包含多行与 `\r`，需要按行拆分逐条提交，并限制单条长度，
超出则在客户端直接拒绝并提示（不发给服务端）。

## 5. 消息区交互

| 按键 | 行为 |
| --- | --- |
| PgUp / PgDn | 上翻/下翻一页 |
| Ctrl-P / Ctrl-N | 上一条/下一条 |
| 滚动到顶且本地无更多 | 自动发 `HISTORY_REQ` |
| 收到新消息且当前在底部 | 自动跟随 |
| 收到新消息且已上翻 | 状态栏显示 `↓ 3 条新消息` |

## 6. 状态与提示

- 连接状态：`●` 在线 / `○` 重连中 / `×` 断开（带倒计时）。
- 本地提示（加入/离开/错误）用灰色 `*` 前缀，与真实消息区分。
- 未确认消息在行尾显示 `…`，失败显示 `!`（重发按 Ctrl-R）。
