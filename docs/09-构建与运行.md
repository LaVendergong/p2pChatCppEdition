# 09 构建、运行与调试

## 1. 环境要求

| 项 | 版本 | 说明 |
| --- | --- | --- |
| WSL | Ubuntu 22.04 / 24.04 / 26.04 | 本机为 Ubuntu 26.04 LTS |
| GCC | ≥ 11（推荐 13+） | 需完整 C++20 支持 |
| CMake | ≥ 3.20 | |
| 其他 | gdb（调试）、valgrind（可选） | |

## 2. 安装工具链（WSL 内）

```bash
# 方式 A：你有 sudo 密码
sudo apt-get update
sudo apt-get install -y build-essential cmake gdb valgrind

# 方式 B：从 Windows 侧以 root 身份安装（WSL 默认 root 免密）
wsl -u root -- bash -c "apt-get update && apt-get install -y build-essential cmake gdb"
```

验证：

```bash
g++ --version && cmake --version
```

## 3. 构建

```bash
cd /mnt/d/projects/mall/chatTerminal

# Release
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"

# Debug + 内存检查
cmake -S . -B build-asan -DCMAKE_BUILD_TYPE=Debug -DCHAT_ENABLE_ASAN=ON
cmake --build build-asan -j"$(nproc)"
```

产物：

```
build/bin/chatd     服务端
build/bin/chatt     客户端
build/bin/cht-load  压测
build/bin/cht-dump  离线转储
build/chat_tests    单测
```

或直接 `bash scripts/build.sh [release|debug]`。

## 4. 运行

```bash
# 终端 1：服务端
./build/bin/chatd --port 7700 --data ./data --threads 4 --log-level info

# 终端 2：alice
./build/bin/chatt --host 127.0.0.1 --port 7700 --user alice

# 终端 3：bob
./build/bin/chatt --host 127.0.0.1 --port 7700 --user bob
```

首次运行账号自动注册（`--allow-auto-register`，默认开，M3 后可用 `--strict-auth` 关闭）。

### 常用参数

| chatd | 说明 |
| --- | --- |
| `--port N` | 监听端口，默认 7700 |
| `--bind ADDR` | 默认 0.0.0.0 |
| `--data DIR` | 数据目录，默认 `./data` |
| `--threads N` | 工作线程数，默认 CPU 核数 |
| `--sync batch\|always\|never` | fsync 策略，默认 batch |
| `--segment-mb N` | 分段大小，默认 64 |
| `--max-room-mb N` | 单房间数据上限（MB），0 = 不限。超限**拒绝写入**并回 `storage_error`，不会删旧数据 |
| `--rate-limit N` | 每连接每秒最大帧数，0 = 关闭（压测用），默认 20 |
| `--log-level trace..error` | |
| `--repair` | 启动时重建索引并修复尾部 |
| `--stats` | 每 60s 打印统计 |

| chatt | 说明 |
| --- | --- |
| `--host/--port` | 服务端地址 |
| `--user NAME` | 用户名 |
| `--room NAME` | 启动后立即加入的房间，默认 `public` |
| `--plain` | 纯行模式（不支持 raw mode 的终端下兜底） |
| `--no-color` | 关闭颜色 |

## 5. 目录与权限

- 数据目录需可写；`chatd` 启动时 `mkdirs` 并检查。
- 建议用专用用户运行：`useradd -r chatd`。

## 6. 调试

```bash
# 崩溃栈
gdb -ex run -ex bt --args ./build-asan/bin/chatd --port 7700

# 内存泄漏（服务端跑完 Ctrl-C 后）
valgrind --leak-check=full --show-leak-kinds=all ./build/bin/chatd --port 7701

# 用 socat 手工发帧（调试协议）
# 十六进制帧头 "CHT1" + 0001 + 0001 + 00000000 + 000000000000000001 + 00000000
printf 'CHT1\x00\x01\x00\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x01\x00\x00\x00\x00' | nc 127.0.0.1 7700 | xxd
```

日志位置：`data/logs/chatd.log`（按 100MB 滚动，保留 5 个）。

## 7. 部署（M6）

```ini
# /etc/systemd/system/chatd.service
[Service]
ExecStart=/opt/chat/bin/chatd --port 7700 --data /var/lib/chatd --sync batch
Restart=always
RestartSec=2
User=chatd
LimitNOFILE=65536
```

`LimitNOFILE` 必须调大，否则 5000 连接时 `accept` 报 `EMFILE`。
